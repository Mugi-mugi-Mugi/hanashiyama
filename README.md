# はなし山 — 西山公園がオチを探す

福井県鯖江市「西山公園」を、県外の人に「え、そうなの?」と思ってもらうための Web アプリです。
オープンデータ活用アプリコンテスト2026 応募作品。

## どんなアプリか

道の駅西山公園のレジに立つ語り手「はなし山」が、あなたに効く**オチ**を探して一席語ります。

はなし山には、3 つの決まりがあります。

1. **西山公園の話から始めない。** あなたの県、あなたの好きなもの、今日の日付から始める
2. **あなたに届く手がかりが無ければ、語らない。** 情報を並べない
3. **「来て」と言わない。** サゲで、あなたが自分で思う

たとえば山口県の人には、吉田松陰の話から始めます。松陰が襲撃を計画した老中は、故郷で領民のための庭を造った殿様でした。その庭が、西山公園のはじまりです。

その噺が使っている数字を**絵図 (棒グラフ) 1 枚**にしてお見せします。
絵図の数値も、台帳の事実に載っている数字しか使いません。
絵図が問いの答えを先に見せてしまう席では、答え合わせのあとに回します
(「約5万株」と「50,025」のような言い換えや、足し算で答えが出る形も見ています)。

語りの終わりに、「札を一枚お出しします」と断ってから、オチを書いた札 (画像) を出します。持ち帰り (保存) できます。
札の写真は「もう一席」のたびに変わります。

噺に入る前に伺うのは**三つだけ**です (行ってみたい気持ち / どちらから / 噺の振りになる思い込み)。
園の入口から来た人と、二度目の人は**二つ**。好きなものを話したい人だけ、もう一つ増えます。
一席は**場面**に分けてあり、画面の上に**いま何の話かを言う見出し** (1 行) を残します。場面が替わると見出しも替わります。
場面の写真は語りの**背景**に敷き、その場面のあいだ出したままにします (写真の隅には、何の写真かと出典をいつも出します)。
写真は**背景**として、紙の色の覆いを掛けて透かし絵のように敷きます。場面の頭でだけ覆いを薄くして写真をはっきり見せ、読んでいた文字は残したまま、写真が入ってから語りを続けます。写真の出入りは 0.3 秒で薄く現れ・薄く消えます。文字の色や行の幅は写真があっても変えません (写真のいちばん黒い所の上でも、本文はコントラスト比 4.5:1 以上)。
数字の絵図の場面では、絵図を上に留めて、語りはその下を流れます (絵図に文字を重ねません)。合う写真の無い場面は、紙の地に見出しだけです。
場面の中でも、画面に大きく出すのは**いま語っている一節と直前の一つ**だけ。前は畳みます (タップで開けます。読み上げには残ります)。
写真のある場面の頭では、写真だけを**一拍 (0.8 秒)** 見せます (タップ・早送りで飛ばせます)。
**サゲ (オチの一行) は写真を下げ、紙の地で**出します。いちばん読ませたい一行を写真に重ねないためです。

一席目は、どこで聴いても完結します。そのうえで、**続きのオチは西山公園の現地に置いてあります。**
一席目のあとに、現地へ行けば分かる謎かけを一つ出し、答えると二席目が開きます
(地図は出しません。次の場所は、席のあとの一言で言います)。
謎かけは、現地で答えを確かめたものだけを出します。

## 文字で語ることの埋め合わせ

高座なら間・抑揚・しぐさで出る温度が、文字だけだと消えます。そのぶんを画面で補っています。

| 高座の芸 | 画面での埋め合わせ |
|---|---|
| 間 | 1 字ずつの打ち出し、読点と句点で止める、**写真のある場面の頭で一拍**、**答え合わせの前に一拍**、サゲの前にタメ |
| 抑揚・声の大小 | まくらは大きく、問いは囲み、**答えは一段大きく**、**サゲはいちばん大きく朱で**、断りは小さく |
| 読む速さ | **小さい字ほど遅く打つ**(字の大きさから速度を決める)。サゲは 1.6 倍ゆっくり |
| しぐさ・目線 | 噺に入る前に**写真 1 枚**、場面ごとに**見出し**と**噺に合う背景の写真** (隅に何の写真かを添える)、本題に**数字の絵図**、最後に**札の写真** |
| 場面の転換 | 見出しの差し替え (「本題」のような段の名ではなく、中身を言う 1 行) |
| 声色の使い分け | 噺家は左、客の答えは右の吹き出し。**動物の噺では本物の鳴き声**(押したときだけ) |
| 客席の反応 | 4 択の問いと、前後で訊く「行ってみたい気持ち」 |

画面の動きは、出るときに一度だけ、0.15〜0.3 秒で薄く現れる・少し動く程度です。端末で「動きを減らす」を設定していると、動きはすべて止まります (写真の一拍は動きではなく間なので残ります)。

噺の途中の画像と札の写真は埋め込み済みの data URI (計 96 枚 = 場面 82 / 札 14)、絵図はその場で組む SVG です。
場面の 82 枚は、**写真 65 枚とイラスト 17 枚**です。
写真はどれも、**自由に使える条件 (クリエイティブ・コモンズ) で公開されているもの**です。写真 65 枚の出どころ:

- 鯖江市オープンデータ 48 枚: つつじ・紅葉・名前の分かるレッサーパンダ・ほかの動物、西山公園や鯖江駅の**古い写真**、西山公園のイルミネーション
- 福井県オープンデータ「福井ふるさと百景」10 枚: 西山公園の夜桜・つつじ・もみじ・嚮陽庭園、西山動物園、恐竜博物館、北潟湖の花菖蒲園
- Wikimedia Commons 7 枚: 北陸新幹線と駅、恐竜博物館の入口、村上市の若林邸、サンドーム福井、西山公園の夜の噴水

イラスト 17 枚は、写真の無い場面を埋めるために画像生成 AI (ChatGPT) を使って作成しました (画面の出典は「イラスト: Mugi-mugi-Mugi」)。
一覧と利用条件は `CREDITS.md` の「イラスト」の節にあります。

鯖江市の公式ページの写真は使っていません (以前の版で使っていた分は、利用条件を確かめ直して外しました)。
**3 枚は CC BY-SA 4.0 (継承あり)** で、その 3 枚を収めたファイル (`app/data/img/` の `*_sa.js`) は CC BY-SA 4.0 で提供します。出典と条件は `CREDITS.md` にまとめています。
写真の隅には**何の写真か**を出します。写真は噺の場面に合わせて選び、**合う写真が無い場面では出しません**。オチや問いの答えを先に見せる写真も置きません。
写真は場所・季節の**群ごとのファイル**に分けてあり、その席に要る群だけを席の頭で読みます (外部への通信は増えません)。
動物の噺では、札のところに「鳴き声を聞く」が出ます。**自動では鳴りません。**
音も埋め込み済みなので、再生しても外部への通信は起きません。
**外部への通信はどれもありません。**

## 語りの約束 — 出典のある事実だけを語る

- 語りはすべて `app/data/facts.json` の**事実台帳**にもとづきます。各事実には出典 URL と原文の引用が付いています
- 台本は台帳の事実 ID しか参照できません
- `tools/validate.py` が、語りに出てくる**数字がすべて参照事実の原文に含まれるか**、不採用にした言い回し (裏付けの取れなかった主張) が混ざっていないかを検査します
- 本題に出す**絵図の数値**も、同じ検査にかけています。問いの答えが絵図に写ってしまう席では、絵図を答え合わせのあとに回します
- 場面の**見出し**も検査します。1 行 16 字まで / 数字を入れない / 「本題」のような段の名だけにしない / **問いの答えとサゲの最後の語を含めない** (見出しがオチの先回りにならないように)。場面が本題の行をすき間なく覆っているか、指定した写真が実在するかも見ます
- 画面の**「タネ明かし」**から、その席の出典と原文を確かめられます
- 出どころによって数が割れているところは、**噺のなかで「噂ですが」の一言**として置いています。
  どちらが正しいと断定しません
- 裏が取れなかった主張 (語らないと決めた話) と、割れている数字の一覧は、
  ビルド時に `data/derived/吟味レポート.md` に書き出します (作り手が読むもの。画面には出しません)
- `tools/check_graph.py` が、噺・事実・登場するものの**つながり**を見て、
  移動・死亡した個体を現在形で語っていないか、同じ取り合わせの噺が重なっていないか、
  出典どうしで数が割れていないかを検査します

## 動かし方

外部との通信はありません。ライブラリも使っていません。

```sh
# そのまま開く
app/index.html をブラウザで開く

# またはローカルで配信する (127.0.0.1 のみ)
python -m http.server 8000 --bind 127.0.0.1 --directory app
# → http://127.0.0.1:8000/
```

日付を指定して確かめる: `index.html?date=2026-11-28`

## データを更新する

```sh
python tools/build.py          # 台帳・台本・飼育記録から app/data/bundle.js を作る
python tools/build_credits.py  # CREDITS.md の出典一覧を事実台帳から作り直す
python tools/validate.py       # 語り・絵図・app.js の文言・出典一覧の検査 (NG なら終了コード 1)
python tools/build_graph.py  # つながり (共起ネットワーク) を作り直す
python tools/check_graph.py  # つじつまの検査
node  tools/test_pick.js      # 噺の選び方・絵図の描画のテスト
node  tools/test_flow.js      # 幕から札まで通しで動くかの煙試験 (最小の DOM で)
python tools/test_figs.py    # 絵図が問いの答えを先に見せていないかのテスト
python tools/test_validate.py # 検査がわざと壊したものを捕まえるか (41 本。正しいものが通るかの 4 本を含む)
python tools/test_css.py     # 画面の動きの決めごと (transform と opacity だけ / 0.15〜0.3 秒 / 一度きり / 動きを減らす設定で止まる)
node tools/test_motion.js    # 操作の試験 (語りの途中で別の噺 / 早送り / 写真の読み込み待ち / サゲの前の畳み / 乱打)
python tools/make_release.py --check  # 公開に入れるもの / 入れないものを一覧する
python tools/measure_gap.py  # オチのズレの大きさを共起ネットワークの上で測る
python tools/test_log_summary.py  # 記録の集計が落ちないかのテスト
```

## 構成

```
app/
  index.html / style.css / app.js   画面 (外部ライブラリなし)
  data/facts.json                   事実台帳 (出典つき)
  data/stories.json                 台本
  data/bundle.js                    自動生成 (手で編集しない)
  data/img/                         写真とイラスト (群ごとの data URI。_keys.js が目録。自動生成)
  data/genchi.json                  現地の謎かけ (現地で答えを確かめた日付が入ったものだけ出す)
  data/kin.js                       全国の動物園からの入口 (自動生成)
  data/koe.js                       レッサーパンダの鳴き声 (data URI。押したときだけ鳴る)
tools/
  build.py                          bundle.js を作る
  figs.py                           本題に出す絵図を、参照している事実から決める
  validate.py                       語りと絵図の検査
  build_graph.py / check_graph.py   つながり (共起ネットワーク) の組み立てと検査
  test_pick.js                      噺の選び方・絵図の描画のテスト
  test_flow.js                      幕から札までの煙試験 (ブラウザ無しで通す)
  report.py                         噂の一言をつける / 吟味レポートを書き出す
  measure_gap.py                    オチのズレの大きさを測る
  read_csv.py                       CSV を文字コードを間違えずに読む (人が知っている値で検算)
  make_release.py                   公開用フォルダを作る (許可制。前回との差分も出す)
  build_credits.py                  CREDITS.md の出典一覧を事実台帳から作り直す
  build_images.py                   写真とイラストを data URI にして data/img/ に群ごとに書き出す
  test_figs.py                      絵図が答えを先に見せないかのテスト
  test_validate.py                  検査の陰性テスト
  test_css.py                       画面の動きの決めごとの検査 (style.css を読む。陰性テストつき)
  test_motion.js / motion_harness.js  操作の試験 (模擬 DOM + 仮想時計。直す前の app.js を渡すと NG が出る)
  test_log_summary.py               記録の集計のテスト
  log_summary.py                    端末に貯めた記録 (気持ちの動き) の集計
data/derived/redpanda_moves.csv     レッサーパンダ飼育個体情報の整形版
data/derived/entities.json          登場するもの (人・場所・個体・記録) と、その注意書き
data/derived/graph.json             つながり (自動生成)
data/derived/吟味レポート.md         足したあとに読むレポート (自動生成)
```
