# はなし山 — 西山公園がオチを探す

福井県鯖江市「西山公園」を、県外の人に「え、そうなの?」と思ってもらうための Web アプリです。
オープンデータ活用アプリコンテスト2026 応募作品。

## どんなアプリか

西山公園に住む語り手「はなし山」が、あなたに効く**オチ**を探して一席語ります。

はなし山には、3 つの決まりがあります。

1. **西山公園の話から始めない。** あなたの県、あなたの好きなもの、今日の日付から始める
2. **あなたに届く手がかりが無ければ、語らない。** 情報を並べない
3. **「来て」と言わない。** サゲで、あなたが自分で思う

たとえば山口県の人には、吉田松陰の話から始めます。松陰が襲撃を計画した老中は、故郷で領民のための庭を造った殿様でした。その庭が、西山公園のはじまりです。

その噺が使っている数字を**絵図 (棒グラフ) 1 枚**にしてお見せします。
絵図の数値も、台帳の事実に載っている数字しか使いません。
絵図が問いの答えを先に見せてしまう席では、答え合わせのあとに回します
(「約5万株」と「50,025」のような言い換えや、足し算で答えが出る形も見ています)。

語りの終わりに、「札を一枚お出しします」と断ってから、オチを書いた札 (画像) を出します。持ち帰り (保存) できます。
札の写真は「もう一席」のたびに変わります。

## 文字で語ることの埋め合わせ

高座なら間・抑揚・しぐさで出る温度が、文字だけだと消えます。そのぶんを画面で補っています。

| 高座の芸 | 画面での埋め合わせ |
|---|---|
| 間 | 1 字ずつの打ち出し、読点と句点で止める、サゲの前にタメ |
| 抑揚・声の大小 | まくらは大きく、問いは囲み、**サゲはいちばん大きく朱で**、断りは小さく |
| しぐさ・目線 | まくらのあとに**小さな写真**、本題に**数字の絵図**、最後に**札の写真** |
| 声色の使い分け | 噺家は左、客の答えは右の吹き出し |
| 客席の反応 | 4 択の問いと、前後で訊く「行ってみたい気持ち」 |

噺の途中の写真と札の写真は埋め込み済みの data URI (計 33 枚)、絵図はその場で組む SVG です。
**外部への通信はどれもありません。**
`app/scenes_preview.html` を開くと、写真を一覧で確かめられます (開発用)。

## 語りの約束 — 出典のある事実だけを語る

- 語りはすべて `app/data/facts.json` の**事実台帳**にもとづきます。各事実には出典 URL と原文の引用が付いています
- 台本は台帳の事実 ID しか参照できません
- `tools/validate.py` が、語りに出てくる**数字がすべて参照事実の原文に含まれるか**、不採用にした言い回し (裏付けの取れなかった主張) が混ざっていないかを検査します
- 本題に出す**絵図の数値**も、同じ検査にかけています。問いの答えが絵図に写ってしまう席では、絵図を答え合わせのあとに回します
- 画面の**「タネ明かし」**から、その席の出典と原文を確かめられます
- 出どころによって数が割れているところは、**噺のなかで「噂ですが」の一言**として置いています。
  どちらが正しいと断定しません
- 裏が取れなかった主張 (語らないと決めた話) と、割れている数字の一覧は、
  ビルド時に `data/derived/吟味レポート.md` に書き出します (作り手が読むもの。画面には出しません)
- `tools/check_graph.py` が、噺・事実・登場するものの**つながり**を見て、
  移動・死亡した個体を現在形で語っていないか、同じ取り合わせの噺が重なっていないか、
  出典どうしで数が割れていないかを検査します

## 動かし方

外部との通信はありません。ライブラリも使っていません。

```sh
# そのまま開く
app/index.html をブラウザで開く

# またはローカルで配信する (127.0.0.1 のみ)
python -m http.server 8000 --bind 127.0.0.1 --directory app
# → http://127.0.0.1:8000/
```

日付を指定して確かめる: `index.html?date=2026-11-28`

## データを更新する

```sh
python tools/build.py        # 台帳・台本・飼育記録から app/data/bundle.js を作る
python tools/validate.py     # 語りと絵図の検査 (NG があれば終了コード 1)
python tools/build_graph.py  # つながり (共起ネットワーク) を作り直す
python tools/check_graph.py  # つじつまの検査
node  tools/test_pick.js      # 噺の選び方・絵図の描画のテスト
node  tools/test_flow.js      # 幕から札まで通しで動くかの煙試験 (最小の DOM で)
python tools/test_figs.py    # 絵図が問いの答えを先に見せていないかのテスト
python tools/test_validate.py # 検査がわざと壊したものを捕まえるか (陰性テスト 13 本)
python tools/make_release.py --check  # 公開に入れるもの / 入れないものを一覧する
python tools/measure_gap.py  # オチのズレの大きさを共起ネットワークの上で測る
python tools/test_log_summary.py  # 記録の集計が落ちないかのテスト
```

手順の詳細は `docs/手順/はなし山_更新と学習の手順.md` を参照してください。

## 構成

```
app/
  index.html / style.css / app.js   画面 (外部ライブラリなし)
  scenes_preview.html               写真の見本 (開発用)
  data/facts.json                   事実台帳 (出典つき)
  data/stories.json                 台本
  data/bundle.js                    自動生成 (手で編集しない)
tools/
  build.py                          bundle.js を作る
  figs.py                           本題に出す絵図を、参照している事実から決める
  validate.py                       語りと絵図の検査
  build_graph.py / check_graph.py   つながり (共起ネットワーク) の組み立てと検査
  test_pick.js                      噺の選び方・絵図の描画のテスト
  test_flow.js                      幕から札までの煙試験 (ブラウザ無しで通す)
  report.py                         噂の一言をつける / 吟味レポートを書き出す
  measure_gap.py                    オチのズレの大きさを測る
  read_csv.py                       CSV を文字コードを間違えずに読む (人が知っている値で検算)
  make_release.py                   公開用フォルダを作る (許可制。作業メモは入らない)
  test_figs.py                      絵図が答えを先に見せないかのテスト
  test_validate.py                  検査の陰性テスト
  test_log_summary.py               記録の集計のテスト
  log_summary.py                    端末に貯めた記録 (気持ちの動き) の集計
data/derived/redpanda_moves.csv     レッサーパンダ飼育個体情報の整形版
data/derived/entities.json          登場するもの (人・場所・個体・記録) と、その注意書き
data/derived/graph.json             つながり (自動生成)
data/derived/吟味レポート.md         足したあとに読むレポート (自動生成)
```
